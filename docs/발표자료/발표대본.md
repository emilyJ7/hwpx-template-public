# hwpx-template 사용자 가이드 — 발표 대본

## 01. 한글 양식, 이제 Claude가 맞춥니다

hwpx-template은 한글 양식을 Claude가 그대로 따라 문서를 만들어 주는 스킬입니다. 오늘은 무엇을 할 수 있는지, 어떻게 설치하는지, 상황별로 어떻게 요청하면 되는지를 차례로 보겠습니다.

## 02. 양식과 내용을 주면, 같은 모양의 한글 문서로

입력은 두 가지입니다. 한글 양식 파일 하나와 넣을 내용입니다. 내용은 마크다운이든 워드 파일이든, 여러 참고 자료든, 대화창에 적은 메모든 상관없습니다. 스킬은 양식에 실제로 쓰인 문단을 보고 서식을 읽어 오기 때문에 따로 스타일을 지정할 필요가 없습니다.

## 03. 보고서부터 매뉴얼 양식까지

개조식 보고서의 제목 상자, 네모 대제목, 동그라미 글머리, 참고 박스, 붙임 상자를 그대로 따라 합니다. 표는 셀 병합까지, 각주와 그림, 머리말과 쪽 번호도 지원합니다. 표지와 목차가 있는 매뉴얼 양식도 됩니다. 같은 스킬 폴더를 Codex나 Cursor 같은 다른 AI 도구에서도 쓸 수 있습니다.

## 04. 쓰는 곳에 따라 할 수 있는 일이 다릅니다

웹 버전 claude.ai에서는 문서를 만드는 데까지 됩니다. 한글 프로그램이 없으니 한글로 열어 보는 검증과 목차 쪽 번호 계산은 안 됩니다. Windows에 한글이 깔린 PC에서 Claude Code로 쓰면 검증과 hwp 변환, 목차 쪽 번호까지 자동입니다. 양식은 빈 서식보다 실제로 작성된 문서가 더 좋습니다.

## 05. claude.ai에서는 zip 하나를 올리면 끝

웹이나 데스크톱 앱에서는 네 단계면 됩니다. 저장소에서 zip 파일 하나만 받고, 설정의 기능 메뉴에서 코드 실행을 켠 다음, 스킬에서 zip을 올립니다. 그리고 새 대화를 열어서 쓰면 됩니다. 가장 흔한 오류는 폴더를 다시 압축해 zip 안에 zip이 들어가는 경우입니다. 메뉴 이름은 화면 개편에 따라 조금 다를 수 있습니다.

## 06. 한글 검증까지 쓰려면 Claude Code로

한글이 설치된 Windows PC에서 Claude Code를 쓰면 만든 문서를 한글로 직접 열어 확인하는 검증과 목차 쪽 번호 자동 입력까지 됩니다. 플러그인으로 설치하면 업데이트도 쉽게 받습니다. 간단하게는 스킬 폴더를 복사해도 됩니다. 설치 후에는 새 대화에서 슬래시 hwpx-template으로 부르면 됩니다.

## 07. 첨부하고, 요청하고, 받아서 확인

쓰는 방법은 단순합니다. 양식과 내용을 첨부하고, 이 양식에 맞게 만들어 달라고 요청합니다. Claude가 양식을 분석하고 원고를 정리해 hwpx를 만들어 줍니다. 받아서 한글에서 열어 보고, 고칠 점이 있으면 같은 대화에서 다시 말하면 됩니다. 어떤 양식으로, 무엇을, 어떤 문서로, 특별히 원하는 것까지 네 가지를 함께 적으면 한 번에 원하는 결과에 가까워집니다.

## 08. 케이스 ① 있는 문서를 양식으로

가장 기본은 이미 있는 문서를 양식으로 옮기는 경우입니다. 마크다운 원고라면 목록과 표를 어떻게 넣을지만 말해 주면 됩니다. 워드 문서는 표와 그림, 각주, 병합 셀까지 그대로 옮겨집니다. 원문 문장을 그대로 두고 싶으면 문장은 고치지 말라고 덧붙이세요.

## 09. 케이스 ② 자료 더미와 메모를 보고서로

여러 자료를 한꺼번에 주고 요약 보고서를 만들 수도 있습니다. 이때는 분량, 구성, 보고 대상, 어투를 정해 주면 결과가 훨씬 안정적입니다. 파일 없이 대화창에 메모만 적어도 됩니다. 사실을 덧붙이지 않길 원하면 메모에 없는 내용은 넣지 말라고 해 주세요.

## 10. 케이스 ③ 표·그림·붙임이 있는 보고서

표나 그래프가 들어가는 보고서도 됩니다. 데이터를 표로 정리하고, 그래프 이미지는 캡션과 함께 넣고, 출처는 각주로 달 수 있습니다. 같은 값이 이어지는 칸은 병합해 달라고 하면 됩니다. 본문은 짧게, 상세 내용은 붙임으로 빼는 구성도 요청할 수 있습니다.

## 11. 케이스 ④ 표지·목차 매뉴얼과 결과 고치기

표지와 목차가 있는 매뉴얼 양식은 표지 글을 바꾸고, 로고를 빼고, 목차를 원고 제목으로 새로 만들어 줍니다. 목차 쪽 번호는 한글이 있는 Claude Code에서 자동으로 채워집니다. 결과가 마음에 들지 않으면 같은 대화에서 이어서 말하면 됩니다. 열 너비, 어투, 분량, 머리말과 쪽 번호까지 문장으로 요청하면 됩니다.

## 12. 케이스 ⑤ hwp 양식과 다른 AI 도구

양식이 예전 hwp 파일이라면 웹에서는 한글에서 HWPX로 저장해서 올리고, Claude Code에서는 hwp를 그대로 주면 자동으로 변환합니다. 이 스킬은 공개 표준 형식이라 Codex, Cursor, Gemini CLI, GitHub Copilot에서도 쓸 수 있습니다. 사용자 폴더의 .agents/skills 아래에 스킬 폴더를 복사하면 이 도구들이 함께 읽습니다.

## 13. 결과를 좋게 만드는 다섯 가지

첫째, 양식은 빈 서식보다 실제로 작성된 문서를 쓰세요. 둘째, 대상, 분량, 구성, 어투, 붙임 여부를 첫 요청에 다 적으세요. 셋째, 요약 과정에서 표현이 바뀔 수 있으니 수치와 고유명사는 한글에서 꼭 확인하세요. 넷째, 다른 곳의 양식을 빌려 쓸 때는 로고와 담당자 이름이 남지 않게 정리를 요청하세요. 다섯째, 잘 된 요청 문구는 모아 두면 다음에 바로 씁니다.

## 14. 막히면 여기부터 확인하세요

스킬이 안 보이면 대부분 새 대화를 열지 않은 경우입니다. 업로드 오류는 거의 다 압축 파일을 다시 묶은 경우라서 받은 zip을 그대로 올리면 해결됩니다. 서식이 조금 다르게 나오면 양식에 그 요소의 예시가 없는 것이니, 예시가 있는 문서를 양식으로 쓰거나 원하는 모양을 말로 알려 주세요.

## 15. 편하게 쓰되, 최종 확인은 사람이

마지막으로 유의사항입니다. 민감한 문서는 소속 기관이나 회사의 보안 지침을 확인한 뒤 올려 주세요. 만든 문서의 최종 확인과 책임은 작성자에게 있습니다. 수치와 고유명사는 한글에서 꼭 다시 확인해 주세요. 저장소는 공개되어 있고, 문의와 제안은 저장소의 Issues로 남겨 주시면 됩니다. 감사합니다.
