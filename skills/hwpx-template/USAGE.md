# 한글 양식 자동 적용 스킬(hwpx-template) 사용 가이드

('26.10.12., 양식 기반 한글 문서 생성·검증)

## 개요

- (기능) 사용자가 준 **한글 양식(hwpx)의 서식을 자동으로 읽어** 같은 모양의 새 한글 문서를 만들고, **한글로 직접 열어 검증**
- (적용 범위) 제목 상자, 날짜 줄, □ 대제목, ○ 글머리, ※ 주석·박스, 붙임 상자, 표(병합 포함), 각주, 그림, 머리말·꼬리말·쪽 번호

> ※ (핵심) 서식 번호를 손으로 맞추지 않고, 양식에 실제로 쓰인 예시 문단에서 서식을 찾아 그대로 사용

## 사용 방법(대화로 요청)

- (1단계) 양식 파일 경로와 원고(내용)를 함께 주며 요청
  - 예: 「C:\...\보고양식.hwpx 양식에 맞게 이 내용으로 한글 파일 만들어줘」
  - 원고는 대화로 설명, docx·md 파일, 기존 보고서 등 무엇이든 가능
- (2단계) Claude가 양식을 한글로 렌더링해 모양을 확인하고 서식을 분석
- (3단계) 원고를 양식 어투(개조식)로 정리해 Markdown 원고 작성
- (4단계) hwpx 생성 후 **한글로 열어 쪽 수·개체 수를 확인하고 쪽 이미지를 양식과 비교**
- (5단계) 결과 hwpx, 원고 md, 그림을 같은 폴더에 저장하고 검증 결과 보고

※ 양식이 .hwp이면 한글로 자동 변환(hwp2hwpx.py)해 사용, 원본은 그대로 둠

## 원고 작성 문법

### 문단

| 원고(Markdown) | 한글 결과 |
|---|---|
| # 제목 | 제목 상자(양식 첫 문단, 글자만 교체) |
| (날짜, 작성 부서) | 제목 아래 날짜 줄 |
| ## 대제목 | □ 대제목 |
| ### 소제목 | 번호 소제목 또는 양식의 두 번째 □ 모양 |
| - 글 | ○ 글머리 |
| - (머리말) 글 | ○ (굵은 머리말) 글 |
| 2칸 / 4칸 들여쓴 - 글 | - 하위 / · 3단계 글머리 |
| ※ 글 | ※ 주석 |
| > 글 | 양식의 강조 박스(1칸 표) |
| 문장 안 \*\*굵게\*\* | 같은 글꼴의 굵은 글자 |

### 붙임·쪽·머리말

| 원고(Markdown) | 한글 결과 |
|---|---|
| # 붙임1 제목 | 새 쪽 + 양식의 붙임 상자 |
| &lt;!-- pagebreak --&gt; | 다음 문단부터 새 쪽 |
| 맨 앞 머리 블록 header: 글 | 머리말(header_align: right 등) |
| footer: - {page} - | 꼬리말 쪽 번호(양식 쪽 번호는 자동 제거) |
| page_number: none | 양식 쪽 번호 삭제 |

### 표·각주·그림

| 원고(Markdown) | 한글 결과 |
|---|---|
| Markdown 표 | 양식 표 서식(회색 머리행 등) |
| 셀에 &lt; | 왼쪽 칸과 가로 병합 |
| 셀에 ^ | 위 칸과 세로 병합 |
| &lt;!-- widths: 20,30,50 --&gt; | 바로 다음 표의 열 너비(%) |
| 글\[^1\] … \[^1\]: 내용 | 각주(양식 각주 서식·번호) |
| !\[캡션\](그림.png){width=60%} | 가운데 그림 + 캡션 |

## 법령 조문 양식

- (자동 인식) 양식에 「제N조(제목)」 조문이 2개 이상이면 조문 모드로 동작
- (머리 부분) 제목·시행일·소관부처 줄과 머리말·꼬리말은 양식 그대로 두고 글자만 교체(원 법령 QR은 제거)

| 원고 | 한글 결과 |
|---|---|
| 제1조(목적) 본문 | 굵은 조 제목 + 본문 |
| ① 본문 / 1. 본문 / 가. 본문 | 항 / 호 / 목(양식 들여쓰기) |
| 줄 끝 &lt;신설 2026. 10. 12.&gt; | 파란 개정 표시 |
| 부칙 &lt;공포번호&gt; + 다음 줄 | 부칙 제목 + 본문 |

## 표지·목차가 있는 양식(매뉴얼·가이드)

- (자동 인식) 점선 목차가 있거나 본문에서 쪽 번호를 1로 다시 매기면 표지·문서 정보·목차 쪽을 양식 그대로 유지
- (목차) 원고 제목으로 새로 만들고 한글로 쪽을 찾아 **쪽 번호 자동 입력**
- (바꿀 글) 원고 맨 앞 머리 블록에 적음

| 머리 블록 | 뜻 |
|---|---|
| replace: 원래 글 => 새 글 | 표지·문서 정보의 글 바꾸기(여러 줄) |
| replace: =개발 => 검토 | 칸 전체가 같을 때만 바꾸기 |
| front_pictures: remove | 표지 로고 등 그림 제거 |
| clear_table: 재·개정 이력 | 해당 표의 내용 비우기 |
| table_row: 0.1 \| 2026-10-12 \| 최초작성 | 비운 표 첫 줄부터 채우기 |

## 검증 방식

- (한글 열기) 한글을 화면 없이 띄워 실제로 열고 쪽 수와 표·그림·각주·머리말 개수를 셈
- (모양 비교) 한글로 PDF를 저장한 뒤 쪽 이미지로 바꿔 양식 이미지와 나란히 비교
- (자동 승인) 보안 승인 모듈을 등록해 두면(setup_windows.ps1) 승인 창 없이 실행, 미등록 시 첫 실행에서 「모두 허용」 선택

## 직접 실행할 때(선택)

```
python -X utf8 analyze_template.py 양식.hwpx style_map.json
python -X utf8 md2hwpx.py 양식.hwpx 원고.md 결과.hwpx --style style_map.json --pdf 검증.pdf --png 쪽이미지
python -X utf8 docx2md.py 원고.docx
python -X utf8 verify_hwp.py 결과.hwpx --pdf 검증.pdf --png 쪽이미지
```

※ 스크립트 위치: 스킬 폴더의 scripts(예: 사용자폴더\.claude\skills\hwpx-template\scripts)

## 유의사항

- 양식에 **예시가 있는 요소만** 그 모양을 따름(예: 하위 글머리 예시가 없으면 ○ 서식에 「-」만 바꿔 씀)
- 같은 각주를 두 번 참조하면 각주가 두 개 생김(한글은 각주 재참조 기능 없음)
- 머리말에 표·그림이 있는 복잡한 양식은 가장 긴 글자만 교체, 여러 구역 양식은 첫 구역 서식만 사용
