# 양식 기반 한글(hwpx) 문서 생성

사용자가 준 **양식 hwpx**에서 서식을 자동으로 읽어 같은 모양의 새 문서를 만든다. 자세한 문법과 예시는 `USAGE.md`.

스크립트: 이 스킬 폴더의 `scripts/` (Python + `lxml`; docx 입력 `python-docx`; 검증 `pywin32`, `pymupdf`, 한글 2018 이상). 한글 경로·콘솔 인코딩 문제를 피하려고 `python -X utf8`로 실행한다(`-I`는 쓰지 않는다).

## 절차

1. **양식 확인**: `.hwp`(법제처 HWPML 포함)면 `python -X utf8 scripts/hwp2hwpx.py 양식.hwp 작업폴더/양식.hwpx`로 먼저 바꾼다(원본은 건드리지 않음). 양식에 실제 예시 문단(□, ○, -, ※, 표, 박스, 붙임, 조문)이 있어야 해당 서식을 읽는다.

2. **양식 렌더링·분석**
   ```bash
   python -X utf8 scripts/verify_hwp.py 양식.hwpx --pdf 양식.pdf --png 양식png   # 양식 모양을 먼저 눈으로 본다
   python -X utf8 scripts/analyze_template.py 양식.hwpx style_map.json
   ```
   - 분석 요약(h1, h1b, h2, h3, bullet1, note, 표, 강조 박스, 붙임 상자, front)을 양식 PNG와 대조한다. 양식에 있는데 「없음」으로 나온 요소, 잘못 잡힌 글자 서식(예: 굵은 서식이 기본 글자로 잡힘)이 있으면 `style_map.json`을 고치거나 분석기를 보완한다.

3. **원고를 Markdown으로 작성** (docx면 `scripts/docx2md.py`로 변환). 양식 어투(개조식 「~함」「~필요」, 명사형)로 쓴다. 문법 요약:
   - `# 제목`, 바로 아래 `(날짜·작성 부서)` → 제목 상자·날짜 줄
   - `## 대제목` → □ 대제목(□가 없는 매뉴얼 양식은 「1. 제목」 모양), `### 소제목` → 번호 소제목(「2.1.」, 없으면 양식의 두 번째 □ 모양 h1b), `#### 소소제목` → 「가.」 모양(h3)
   - `- 글`, `- (머리말) 글`, 2칸/4칸 들여쓰기 → ○ / - / ·
   - `**굵게**` → 같은 글자 서식의 굵은 판(양식에 없으면 header.xml에 새로 추가)
   - `> 글` 줄들 → 양식의 1칸 강조 박스(없으면 ※ 주석), `※ 글` → ※ 주석
   - `# 붙임1 제목` → 새 쪽 + 양식의 붙임 상자(없으면 새 쪽 대제목), `<!-- pagebreak -->` → 새 쪽
   - 머리 블록 `header:` / `footer:`(`{page}`) / `header_align:` / `page_number: none`
   - `글[^1]` + `[^1]: 내용` → 각주, `![캡션](그림.png){width=60%}` → 그림
   - 머리 블록 `footer_reset: true`(양식 꼬리말·로고를 지우고 새로), `keep_pictures: true`(법령 머리 부분 QR 등 유지)
   - **법령 조문 모드**(양식에 「제N조(제목)」 조문이 2개 이상이면 자동): 첫 조문 앞 머리 부분(제목·시행일·소관부처, 머리말·꼬리말)은 양식 그대로 두고 글자만 교체한다. 원고는 `# 제목` 다음 줄들 = 시행일 줄·소관부처 줄, 이후 `제1조(목적) 본문`, `① 항`, `1. 호`, `가. 목`, `제1장 …`, `부칙 <공포번호>` + 다음 줄 본문. 줄 끝 `<개정 2026. 10. 12.>`·`<신설 …>`은 양식의 파란 개정 표시로. 원 법령 전용 QR 그림은 기본 제거, 공식 문서로 오인되지 않도록 시안 표시(예: 「[규정(안) 시안]」)를 시행일 줄에 넣는다.
   - 표: `<!-- widths: 20,30,50 -->`, 셀 `<`(왼쪽과 병합) `^`(위와 병합) `<br>`(줄바꿈)
   - **앞쪽 페이지 모드**(양식에 점선 탭 목차가 있거나, 첫 쪽 뒤에서 쪽 번호를 1로 다시 시작하면 자동 — 분석 결과 `front`): 표지·문서 정보·목차 쪽은 양식 그대로 두고, 본문은 새 쪽에서 쪽 번호 1부터. 원 양식에서 새 쪽이던 문단에는 쪽 나눔을 명시한다. 머리 블록:
     - `replace: 원래 글 => 새 글`(여러 줄 가능, 글 일부 일치) / `replace: =원래 글 => 새 글`(칸 전체가 같을 때만 — 「개발」 같은 짧은 낱말). replace가 없으면 `# 제목`이 표지의 가장 큰 글자를 바꾼다.
     - `front_pictures: remove`(표지 로고 등 제거 — 다른 기관 양식을 빌려 쓸 때), `clear_table: 재·개정 이력`(표 제목이나 표 안 글로 찾아 머리행 외 비움) + `table_row: 0.1 | 2026-10-12 | 최초작성 | …`(비운 표 첫 줄부터 채움)
     - 목차는 원고의 `##`/`###`(양식 목차에 3단계가 있으면 `####`도)로 새로 만들고, Windows+한글이면 PDF로 제목 쪽을 찾아 **쪽 번호를 자동으로 채운다**(2단계 실행). `front: none`이면 앞쪽 페이지 모드를 끈다.
     - 다른 기관 양식을 빌려 쓰면 로고·담당자 실명(재·개정 이력 등)이 남지 않게 `front_pictures: remove`, `clear_table:`을 쓴다.

4. **변환 + 한글 검증**
   ```bash
   python -X utf8 scripts/md2hwpx.py 양식.hwpx 원고.md 결과.hwpx --style style_map.json --pdf 결과_검증.pdf --png 결과png
   ```
   - 앞쪽 페이지 양식은 목차 쪽 번호 계산을 위해 한글로 한 번 더 연다(「목차 쪽 번호 계산: n/n」 확인).
   - 결과 JSON의 `ok`, `pages`, `tables`(= 제목 상자 + 박스 + 표 + 붙임 상자 + 앞쪽 페이지 표), `pictures`, `footnotes`, `headers`를 원고와 대조한다.
   - **결과 PNG 이미지를 열어 양식 PNG와 나란히 비교**한다(이미지를 볼 수 없는 환경이면 PDF 글자와 결과 JSON으로 대신 확인): □ 띄어쓰기, ○ 기호·본문 글자 크기, 머리말 굵기, 박스·붙임 상자, 표 머리행·열 너비, 쪽 번호 겹침, 그림 크기. 다르면 2단계로 돌아가 고친다.
   - 보안 승인 창은 등록된 FilePathCheckerModule로 피한다(없으면 첫 실행 때 사용자에게 「모두 허용」 요청).
   - 경로에 괄호 등이 있으면 한글 자동화 열기가 멈추므로 verify_hwp·hwp2hwpx는 임시 폴더의 단순한 이름 복사본으로 연다. 그래도 응답이 없으면 `--timeout`(기본 90초) 뒤 **검증용으로 띄운 한글만** 종료한다(사용자가 열어 둔 한글 창은 건드리지 않음).

5. 결과 hwpx를 원고 md·그림과 같은 폴더에 저장하고, 검증 결과(쪽 수, 개체 수, 양식과 다른 점)를 보고한다. 검증 PDF는 요청이 없으면 내부 확인용.

## 유의
- 같은 각주 번호를 두 번 참조하면 한글에서는 각주가 두 개 생긴다.
- 양식에 하위 글머리(-) 예시가 없으면 ○ 문단 서식에 「-」만 바꿔 쓰므로 둘째 줄 들여쓰기가 양식과 다를 수 있다.
- 머리말에 표·그림이 있는 복잡한 양식은 가장 긴 글자만 교체한다. 구역이 여러 개인 양식은 첫 구역 서식만 쓴다.
